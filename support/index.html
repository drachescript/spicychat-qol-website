Bug report

The useful bits.

  • Browser + device/platform
  • Stable or DEV, and version if known
  • What SpicyChat page it happens on
  • What you expected
  • What actually happened
  • Steps that reproduce it
  • QoL diagnostics/support report when relevant

Do not post private chat text, API keys or other sensitive content just to prove a UI bug.

QoL Bot v0.3.9

Useful public bot commands.

The Discord bot keeps project messages synced and can also notify you when a watched public SpicyChat creator publishes something new.

  • /links, /version, /support, /download
  • /main, /dev, /android, /knownissues
  • /follow creator, /follow list, /follow remove

Creator follows baseline existing public bots first, so notifications are for later discoveries. NSFW bot art is not pushed into DMs.
