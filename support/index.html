Bug report

The useful bits.

  • Browser or Android device/platform
  • QoL version/build if known
  • Affected SpicyChat page/route
  • What you did
  • What happened vs what you expected
  • Steps that reproduce it
  • Settings → Advanced diagnostics/support info when useful

Do not post private chat text, memories, API keys, webhook secrets or other sensitive content just to prove a UI bug.

QoL Bot v0.3.18

Useful public commands.

The bot keeps project information easy to reach and can optionally watch public SpicyChat creators for new public bots.

  • /links, /version, /support, /faq
  • /download, /main, /android, /knownissues
  • /follow creator, /follow list, /follow remove, /follow settings

Creator-follow filters are per user. NSFW alert art is not pushed into DMs.
