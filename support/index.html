Bug report

The useful bits.

  • Browser + device/platform
  • Stable or DEV, and version if known
  • What SpicyChat page it happens on
  • What you expected
  • What actually happened
  • Steps that reproduce it
  • QoL diagnostics when relevant

Do not post private chat text or other sensitive content just to prove a UI bug.

Suggestion

Problem first, idea second.

The easiest feature requests to understand explain what is annoying or missing first, then the proposed improvement. You do not need to know how it should be coded.

If the feature already exists in DEV or is planned, the feature page should make that visible once its GitHub source is live.
