Compatibility notices

One place for real breakage.

If a SpicyChat site change breaks a QoL feature badly enough to affect lots of people, the top-of-site status banner can be switched from the normal project update to a compatibility incident.

Known issues also belong in the QoL Discord so users do not have to guess whether a bug is already known.

Why DEV numbers differ

Chrome ≠ Firefox ≠ local dev.

A DEV version shown in a browser store means that exact submitted build. Small local development changes may happen between store uploads, and Chrome/Firefox review/upload timing is separate. The site therefore reads each public distribution independently instead of using one manifest number for everything.
