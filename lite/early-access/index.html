QoL Custom · experimental early access

Install only what you need.

Here's our first genuinely small Custom build: the shared OOC insert tools and composer button, without the rest of Full QoL. It uses the same OOC feature code as Full, with a minimal Core and Settings page.

Step 2 · Enable once

Load the folder in your browser

1

Open extensions

In Chrome, open chrome://extensions. In Brave, open brave://extensions. Turn on Developer mode.

2

Load unpacked

Choose Load unpacked and select the directory the site populated (or the folder where you extracted the downloaded ZIP).

3

Try OOC

Open a SpicyChat conversation, try inserting a preset, and check the extension's small Settings page. Test in a separate browser profile from Full QoL.

Step 3 · Update later

Keep the same folder and your settings

Come back to this page when a newer early-access release appears. Choose Install / update selected folder, allow access to the same directory and approve the update. The page verifies each pinned source file before writing, backs up the previous files, and writes the new manifest last.

Important: After changing files, open the extensions page and click Reload for Core + OOC. Fully automatic reloads and update checks while the website is closed are not implemented yet. The site can remember your folder choice locally, but browser permissions may still need approval.

Replacing files in the same unpacked extension folder preserves that extension's browser storage. Installing it alongside Full QoL creates separate extension storage; you can import/export your OOC presets as JSON.
