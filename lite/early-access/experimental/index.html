Installation

One unpacked installation, updates through the website

Chrome/Brave desktop · Developer Mode required

1

Build & choose folder

Choose modules, then click Install / update folder. Grant access to an empty folder or to a previous QoL Custom early-access folder. Or download the ZIP and extract it.

2

Load unpacked

Open chrome://extensions or brave://extensions, enable Developer Mode, choose Load unpacked and select the folder.

3

Try it & update

Test the modules and report issues. Come back here to add/remove groups or update; the site backs up existing files first. Click Reload in extensions after updating.

Current limitations

Chrome/Brave only for folder installation. Firefox builds, fully automatic updates, and exact per-feature dependency isolation are not ready yet. Selecting every group approaches Full QoL's package size. Builds can be broken even if the file checks pass.
