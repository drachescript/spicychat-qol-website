Installation

One unpacked installation, updates through the website

Chrome/Brave desktop · Developer Mode required

1

Build & choose folder

Choose your tools, then select Install / update folder and pick an empty folder. The website puts the files there. Or click Download Custom ZIP, save it, and extract the ZIP into a folder before continuing.

2

Load unpacked

In Chrome, enter chrome://extensions in the address bar. In Brave, use brave://extensions. Turn on Developer mode, choose Load unpacked, and select the folder containing manifest.json.

3

Try it & update

Open SpicyChat and try your tools. To change your selection or update later, return to this page and choose the same folder. Your browser may ask permission again. Once the update finishes, click Reload on the extension's card.

Current limitations

This Chrome/Brave build is experimental, not a finished extension. Firefox Custom builds aren't ready, and updates don't happen automatically while the site is closed. Some tool combinations may be broken. Tell us if anything fails!

Firefox users

What about Firefox?

Firefox needs a different extension package, so please don't install the Chrome/Brave ZIP there. Firefox Custom is still being prepared.

For now: use the regular Firefox QoL release linked from the Extension page. U can still try the builder here and save or share your module-selection code.

When Firefox Custom builds are available: we'll provide a Firefox-compatible download and instructions. Firefox's about:debugging#/runtime/this-firefox page can load an extension temporarily for development, but temporary add-ons disappear when Firefox restarts. A permanent installation needs an appropriately signed add-on.
