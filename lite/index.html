Getting started

How do I install QoL Custom?

It's a test version, so there are a few extra steps. U only need to do the setup once.

1

Chrome or Brave

Select your tools and click Build experimental Chrome / Brave ZIP. Download the ZIP and extract it into a folder (don't load the ZIP itself). Open chrome://extensions or brave://extensions, enable Developer mode, click Load unpacked, then pick the extracted folder.

2

Want easier updates?

On the early-access builder, choose Install / update folder instead of downloading a ZIP. Pick an empty folder the first time; the website will fill it for u. Load that folder once using Load unpacked. For later updates, choose the same folder, then click Reload on the extensions page.

3

Firefox

Custom downloads aren't Firefox-compatible yet. Firefox requires a different extension package and additional checks. For now, use the normal Firefox QoL version on the Extension page. Firefox Custom testing will be added when its package is ready.

Early access means bugs can happen!

Test in a separate browser profile from Full QoL if possible. Some modules or combinations might not work yet. Make a backup of your QoL settings and share any problems u run into.
