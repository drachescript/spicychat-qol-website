Installation help

How to install QoL Custom

Chrome and Brave can load an unpacked extension from a folder. U only need to do this once.

1

Get your files

Select features and click Download Custom ZIP, then extract it into a folder. Or choose Install / update folder and let the website place the files into an empty folder.

2

Load it in Chrome / Brave

Open chrome://extensions in Chrome or brave://extensions in Brave. Turn on Developer mode, click Load unpacked, and select the folder with manifest.json.

3

Change it later

Return here, adjust the individual features and update the same installation folder. The website backs up older files before updating. Click Reload for the extension afterwards.

Firefox users

Firefox Custom packages need their own build and signing. For now, use the normal Firefox QoL extension. Custom ZIPs from this page are for Chrome/Brave.

Firefox developers can temporarily load an add-on using about:debugging#/runtime/this-firefox, but temporary installs disappear on restart. Permanent Firefox Custom installs are not ready yet.
