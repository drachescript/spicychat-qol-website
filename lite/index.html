Installation help

How do I use my Custom build?

Chrome and Brave can load your experimental extension from a folder. The setup is only needed once.

1

Download or choose a folder

Click Download Custom ZIP and extract it into a folder, or use Install / update folder and choose an empty folder for the website to fill. Don't try to load the ZIP directly.

2

Load it in Chrome / Brave

Open chrome://extensions (Chrome) or brave://extensions (Brave). Enable Developer mode, click Load unpacked, and select the folder containing manifest.json.

3

Change or update it

Return to this page, adjust your selection, and choose the same folder when updating. The site backs up the previous files. Then click Reload for the extension in your browser.

What about Firefox?

Firefox needs its own add-on package, and Custom isn't ready for Firefox yet. You can use the normal Firefox QoL extension in the meantime. Firefox Custom installation instructions will be added when a compatible package is available.

For temporary developer testing, Firefox can load an unpacked extension through about:debugging#/runtime/this-firefox, but it won't stay installed after Firefox restarts. A permanent Firefox installation needs a signed add-on.
