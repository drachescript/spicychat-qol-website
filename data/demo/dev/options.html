Timestamps and generation details

Existing messages can show timestamps, model, and saved generation settings when SpicyChat provides them. Generation time is only available for replies created while this feature is enabled.

Composer and draft helpers

The OOC button inserts the preset currently selected in the mini panel. If Hide image generation button is enabled, OOC uses that button's slot; otherwise Image stays visible and OOC appears beside it.

Select text and press * to wrap it in asterisks for actions. With no selection, it inserts ** and puts the cursor between them. This is intended to stay usable on touch/mobile too.

Auto * turns a typed * into ** with the cursor between them, so you can type the action without manually adding the closing asterisk.

The send button may still wait for SpicyChat to finish, but this lets you keep drafting your next message.

Scroll navigation

The arrows only appear when there is somewhere useful to jump. If both are enabled, they stack together. Home/listing/profile pages use a smaller faded bubble so it stays out of the way, especially on mobile.

Performance

QoL automatically prioritizes blocking/opened filtering and direct chat controls before cosmetic cleanup. Long-chat mode keeps far-away messages lighter using viewport-aware rendering; the hidden-tab option further reduces work in background tabs.

Message options

Adds small quick-action icons to chat messages, using SpicyChat's own Copy/Edit/Report actions.

Chat export

Exports are cleaner now: messages are grouped by speaker, and bot info stays separate from the chat.

Persona helpers

Saved personas: 0 stored. The quick-switch uses saved personas from /personas or the Change Persona picker.

Creation helpers

The visibility helper only sets the initial choice on /chatbot/create. You can still change it manually before saving.

The Lorebook Start New helper only acts on the chooser at /lorebook/create and leaves Import alone. Lorebook entry expand buttons only change how entry text is displayed locally; clicking the entry itself still opens SpicyChat's normal editor.

The guidelines helper only targets the agreement checkbox on /chatbot/create and /lorebook/create.

Chatbot shortcuts

Chats opens SpicyChat's own View Saved Chats screen for the current character. + uses SpicyChat's normal Start New Chat action, so the current conversation is saved normally.

The Later close-tab option only closes when a bot is added to Later. Removing it from Later keeps the chat open.

Bot editor snippets

Adds small insert buttons above longer fields while creating or editing a chatbot. Text is inserted at the current cursor position.

Custom snippets

Useful for reusable personality, scenario, greeting, or formatting text.

Persistent OOC-style rules belong in Personality or Scenario. The normal OOC tool only inserts into the user side of a chat.

Bot tags in chats

Clicking a tag opens the Home page with that tag included. The + button adds it without replacing tags already saved in your include list.
