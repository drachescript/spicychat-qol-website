# SpicyChat QoL stable features

The stable Chrome Web Store build is currently v0.1.5. This bundled list is used until the full stable repository root files are uploaded.

## Filtering and bot lists
- Block or hide bots by bot, name, creator, tags, or words.
- Not Interested list.
- Track opened chats and optionally hide or dim bots already opened.

## Chat and organization
- Chat search and sorting plus Load More / Load All tools.
- OOC messages and saved OOC presets.
- Persona detection and quick persona switching.
- Basic chat export.

## Interface and data
- Hide premium/promotional UI and other unwanted interface elements.
- Import/export QoL settings and saved data.
- Individual feature toggles and sidebar cleanup options.
