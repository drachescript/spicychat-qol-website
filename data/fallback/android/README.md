# SpicyChat QoL Android

SpicyChat QoL Android is the open-source Flutter/WebView wrapper for SpicyChat QoL.

- Android wrapper: https://github.com/drachescript/spicychat-qol-android
- Main extension/shared QoL source: https://github.com/drachescript/spicychat-qol-extension
- Website/downloads: https://spicychatqol.drache.uk/android/
- Issues: https://github.com/drachescript/spicychat-qol-extension/issues (use the `android` label for wrapper-specific reports)

The Android project provides native WebView recovery/navigation, Android settings, storage/file/clipboard bridges, diagnostics, native long-press message actions and experimental opt-in multiple chat tabs while synchronizing the shared QoL JavaScript/CSS from the extension project.

The source is public. A public GitHub APK release is still pending; the website will surface one automatically once published.
