# SpicyChat QoL features

Everything is optional. Fresh installs keep the main extension switch on, but the actual QoL features stay off until the user enables them or applies a setup preset.

## Setup and compatibility
- Search across every Settings tab.
- Minimal and recommended setup presets, plus a one-click way to turn optional features back off.
- Passive S.AI Toolkit detection with optional compatibility handling for overlapping features.
- Install/update notice in the extension popup and NEW/UPDATED markers for recent settings.
- Safe diagnostic copy for bug reports without chat text or saved private content.

## Saved lists and bot discovery
- Opened-chat tracking, hiding, search, sorting, and management.
- Favorite bot history, including bots that were later unfavorited on SpicyChat.
- Favorite creators with optional filter protection.
- Later list with card and chat-page buttons, plus optional filtering/hiding behavior.
- Blocked and Not Interested lists with search, sorting, links, and local management.
- Undo for local list removals and recently cleared opened-chat history.

## Card and listing tools
- Block/filter by tags, words, creators, bot IDs/names, groups, language, opened chats, and other saved states.
- Optional Home For You cleanup.
- Optional longer card descriptions.
- Optional listing refill after cards are hidden.
- Text normalization for filters/search.

## Chat tools
- Chat top-bar cleanup and bot shortcuts for Later, chat history, and new chats.
- Saved-conversation quick actions for Change Title, Clone, and Remove.
- OOC presets and optional OOC composer button.
- Formatting/composer helpers for `*`, `[ ]`, and `{ }`, including optional automatic asterisk pairing.
- Message quick actions, draft protection, failed-message helpers, and typing/scroll-position helpers.
- Optional scroll-to-top and scroll-to-bottom bubbles.
- Bulk Memory Manager with multi-select, Select unpinned, Pin selected, and Delete selected.
- Generation profiles, timestamps, model/engine details, elapsed time, and captured generation settings where available.
- Chat export with optional bot info/OOC details.
- Persona saving, quick switching, and per-persona description expansion.
- Lorebook entry Show full text / Show less controls.
- Auto voice for new AI replies using SpicyChat's native Listen control when available.
- Long-chat performance mode and optional background-tab QoL pausing.

## Creation tools
- `{{char}}`, `{{user}}`, CONTINUE, no-control, and custom editor snippets.
- Optional automatic Advanced-section opening.
- Optional automatic Start New on Create Lorebook.
- Optional default Public or Unlisted visibility for newly created chatbots.
- Optional automatic Community Guidelines agreement.
- Clickable chat-page bot tags with shortcuts for saved tag filters.

## Interface cleanup
- Individual sidebar and top-bar cleanup switches.
- Chat composer cleanup for plus/image/voice controls and voice upsells.
- Premium, notification, model, and advert/banner cleanup.
- Optional browser-tab notification badge hiding and background product-update clearing.
- Mini Panel with configurable placement, drag position, sizing, visible controls, Auto voice/Auto * toggles, and an optional current-page feature summary.
- Optional Auto-AFK cleanup for inactive SpicyChat tabs.

## Data and backup
- Export by category or export everything.
- Import preview before anything changes.
- Merge or replace only the categories included in an imported backup.
- Storage usage details in Settings and optionally in the popup.
- One-click cleanup for duplicate IDs and orphaned local metadata.
