## 0.2.0
- First main public release from the long 0.1.9.x DEV/testing cycle.
- The former DEV extension is now the actively maintained SpicyChat QoL release.
- Existing DEV users keep supported settings and local QoL data without a reinstall/reset.
- Includes the current Saved Bots Hub/Bot Organizer, discovery filters, chat search/bookmarks/exports, Reply Instructions, Chat Nudges, Context Keeper, Storydate, RP State Tracker, Persona/Memory/Lorebook tools, creator backup/audit tools, performance/diagnostic work and more.
- Storydate and RP State are scoped per exact conversation rather than bot-wide.
- Source is public under GPL v3.

## 0.1.9.x testing cycle
- The exact per-build history is intentionally loaded from the public GitHub `CHANGELOG.md` when available.
- This bundled fallback is only used if GitHub cannot be reached, so it does not try to duplicate more than a thousand lines of live release history.
