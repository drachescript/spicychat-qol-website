Features

More control without replacing SpicyChat.

The extension runs on top of SpicyChat and adds optional controls that can be enabled or disabled individually.

01

Cleaner interface

Hide premium prompts, voice controls, buttons, chips, and other interface elements you do not use.

02

Bot controls

Hide or block individual bots, manage blocked characters, and refill empty card slots where supported.

03

Opened-chat tracking

Mark characters you have already opened, dim or hide them, and keep a separate view of opened chats.

04

Chat loading and sorting

Load more chats, stop long loading tasks, and sort conversations using additional order options.

05

Persona and OOC tools

Improve persona switching, reduce repeated mobile prompts, and save reusable OOC blocks and templates.

06

Export and backup

Export settings and supported chat or character data so your configuration is easier to move or restore.

Feature availability can vary between the browser extension and Android app. Experimental features are labelled in release notes.

FAQ

Common questions.

Is SpicyChat QoL official?

No. SpicyChat QoL is an independent community project and is not affiliated with or endorsed by SpicyChat.

Which browsers are supported?

The extension is intended for Chromium-based desktop browsers such as Chrome, Brave, and Edge. Support can vary by browser version.

Will the extension update automatically?

Yes, when it is installed through the Chrome Web Store. Manually loaded developer builds must be updated manually.

How will Android updates work?

The Android app will check this website's update metadata. When a higher version code is available, it can open the signed APK download and Android's normal installer.

Does the website collect account passwords?

No. This static website does not provide a SpicyChat login form. Review the project privacy policy for details about the extension and app.
