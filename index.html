Browser extension + Android app

More control over SpicyChat.

I made SpicyChat QoL to add stuff I kept missing while using SpicyChat. It adds extra UI settings, chat tools, bot hiding, persona improvements, exports and a bunch of smaller things that make the site less annoying to use.

Features

Extra settings and tools without replacing SpicyChat.

Everything is optional, so you can just enable the parts you actually care about.

01

UI cleanup

Hide premium prompts, voice buttons, chips, banners and other parts of the UI you do not use.

02

Bot hiding and blocking

Hide individual bots, manage blocked characters and keep them out of recommendations or searches.

03

Opened chat tracking

Mark characters you already opened, dim them or hide them so it is easier to find something new.

04

Loading and sorting

Load more chats, stop longer loading jobs and sort conversations with extra options.

05

Persona and OOC tools

Extra persona switching help, less annoying mobile popups and reusable OOC templates.

06

Exports and backups

Export settings and supported chat or character data so it is easier to move or restore later.

Some features are still experimental and some work differently between the extension and Android app.

FAQ

A few common questions.

Is SpicyChat QoL official?

No, not right now. I contacted SpicyChat about the project and I am waiting to see if they reply. So they know I am trying to reach them, but unless they confirm anything this stays an unofficial community project.

Which browsers work?

It is mainly made for Chromium-based desktop browsers like Chrome, Brave and Edge.

Does the extension update automatically?

Yes when it is installed from the Chrome Web Store. Developer or manually loaded builds have to be updated manually.

How will Android updates work?

The app will check the public update file on this website and open the newest signed APK when there is a newer version.

Will there be a Discord server?

Yes, I plan to make one later for announcements, help, bug reports and feature ideas. For now GitHub issues are the best place.
