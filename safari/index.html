Why not a full iOS app?

I'm prioritizing the actual extension instead.

A proper native Safari/iOS release means Apple-specific packaging and testing, plus the $99/year Developer Program for normal App Store distribution. I don't have Apple hardware for testing, and I don't want to spend that money for a port I can't properly maintain.

So Safari Lite is the compromise: a free userscript with a few useful organizer features. If you want more of the normal extension, Orion can also attempt to install the normal Firefox extension on iOS, but that setup isn't a guarantee of full compatibility. Install on iPhone or iPad

Five steps, no paid app needed.

The script is the .user.js file, not the ZIP itself.

  1. 1
    Install Userscripts.

    Get the free Userscripts app and check its script folder in the Files app.

  2. 2
    Enable it in Safari.

    Open Settings → Apps → Safari → Extensions → Userscripts, enable it, and allow access to spicychat.ai. Older iOS versions may show Safari directly under Settings.

  3. 3
    Save the script.

    Download spicychat-qol-safari-lite-v0.1.0-beta.1.user.js into the Userscripts folder. Or open the direct .user.js link in Safari and install through the Userscripts extension menu.

  4. 4
    Open SpicyChat.

    Reload spicychat.ai in Safari. Check the Userscripts menu if needed; a little QoL launcher should appear.

  5. 5
    Enable your features.

    Tap QoL → Setup. Start with Quick-save and Chat folders. If something breaks, open QoL → Diagnostics and send me the report.

Safari Lite beta 1

What's included?

It's a smaller build focused on the things requested by Safari testers, not a full port of QoL.

Chat folders

Put chats into folders, and rename or remove them.

Bot organizer

Folders, notes, tags and filters for your saved bots.

Saved lists + quick-save

Keep local Favorites/Later and add bots from loaded cards.

Local discovery

Search loaded listings or saved records. No full online discovery or archive index.

JSON backups

Export, import and restore supported local data.

Diagnostics

Copy a diagnostic report when something goes wrong.

Before you try it

It's still a beta.

It hasn't been verified on a real iPhone or iPad yet. Safari storage is separate from Chrome, Firefox and Android. Clearing website data can erase it. Export backups, and remember that importing a Safari Lite backup replaces current data, not merges it.

There are no background workers, global blocklists, bulk archive imports, automatic sync, or tab-dependent extras. Native SpicyChat Favorites aren't copied into QoL's own local lists automatically.

Reporting a problem

Please include your device, iOS version, the SpicyChat page, what failed and the QoL Diagnostics report. No private chat text or secrets.
