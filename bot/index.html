QoL Bot v0.3.18

Use QoL Bot without joining the server.

Install QoL Bot to your Discord account and the public commands can follow you into DMs, group DMs and servers where external apps are allowed. You can use things like creator follows without becoming a member of the SpicyChat QoL server first.

Installing the user app only gives you the public command set. Staff and server-management commands stay locked to the SpicyChat QoL server.

Most useful outside the server

Follow creators and get new-bot DMs.

The creator watcher is one of the main reasons to install the bot as a user app. It watches public SpicyChat creator listings and sends you a DM when a newly published public bot appears.

Creator follows

/follow creator

Pick a public SpicyChat creator and a check interval. The first check creates a baseline, so old bots are not dumped into your DMs as if they were new.

  • /follow creator — start watching a creator
  • /follow list — see who you currently watch
  • /follow remove — stop a watch
  • /follow settings — adjust your follow preferences
Public data only

No SpicyChat login needed.

Creator discovery uses public SpicyChat creator/bot listings. QoL Bot does not store a SpicyChat login, session or cookies for this.

Safe bot art can be included in the DM. NSFW bots are still detected, but their alert is text-only instead of pushing NSFW imagery into Discord.

Where it works

Your account, not just one server.

A Discord user-installed app can be used in your DMs, group DMs and servers you are already in, as long as that server allows external apps/application commands.

Scope

Public commands stay public.

The user install does not turn QoL Bot into a moderation/admin bot for other servers. Staff messaging, managed server messages and other server-management commands remain restricted to the QoL server and authorized staff.
