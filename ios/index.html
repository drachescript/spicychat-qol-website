SpicyChat QoL
on iOS.

There's no separate iPhone app, but there are two ways you can try some QoL features: the normal browser extension through Orion, or the smaller Safari Lite userscript beta.

Both routes are experimental, and neither is a promise that everything from desktop QoL will work on your phone.

How to use QoL on iOS

Pick whichever setup works for you.

Orion attempts to run the regular extension. Safari Lite is a separate, deliberately reduced build designed for the Userscripts app.

O
Option 1 · Orion Browser by Kagi

Try the regular extension

Orion can install some Firefox and Chrome extensions on iPhone and iPad. Its extension support is still experimental, so QoL may not load or individual features may not work.

  1. Install Orion Browser from the App Store.
  2. In Orion, open the three-dot menu → Settings → Extensions, then enable Firefox extensions.
  3. Open Orion's Extensions menu, use the add (+) option, and open the SpicyChat QoL Firefox add-on listing in Orion to try installing it.
  4. Open SpicyChat in Orion and check whether QoL loads and the features you need work.

Important: This is not a tested or officially supported iOS port. If it crashes, breaks SpicyChat, or fails to inject, disable the extension in Orion. Not all browser APIs are available.

Option 2 · Safari

Try Safari Lite beta

Safari Lite goes back to QoL's userscript roots. It's a smaller, free beta focused on chat folders, bot organization, saved lists, quick-save, local discovery and backups.

  1. Install the free Userscripts app.
  2. Enable Userscripts in iOS Settings → Apps → Safari → Extensions, and allow it for spicychat.ai. On older iOS versions the path may be Settings → Safari.
  3. Open the Safari Lite beta page, download the .user.js file and install or save it in the Userscripts folder.
  4. Reload SpicyChat in Safari. Use the QoL launcher and turn on only the options you want.

Important: Beta 1 hasn't been tested on a real iPhone by me. It doesn't include the full extension, and its local data doesn't automatically sync with Chrome, Firefox or Android. Export backups regularly.

Why no iOS app?

i can't properly test one.

I don't own an iPhone or Mac to build and test a native iOS release on, and I'm not paying $99 every year for Apple's Developer Program just to distribute an App Store app I can't even test myself xD.

That's not a claim that every iOS experiment costs $99 — it's the annual fee for the normal Apple Developer Program/App Store distribution route. For now i'd rather keep working on the extension and offer free alternatives without pretending they have full compatibility.

Safari Lite is the experiment I can make available without a native app. Orion is another possible route, but it depends on Orion's extension compatibility.

What's actually supported?

Chrome/Chromium and Firefox remain the main browser extension platforms. Android has its own app. These two iOS routes are community testing options, not replacements for a proper tested native app.
