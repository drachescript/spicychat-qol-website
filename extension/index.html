What the extension includes

The main QoL feature areas.

A shorter overview of the current public v0.2 line. Most tools are optional and start switched off. Some account-specific features only appear when SpicyChat makes them available.

Saved bots and organization

Favorites, Later, Blocked, Recently Seen and bot history in searchable managers. Add your own folders, tags, notes, creator preferences and saved-list shortcuts.

Discovery and card filters

Hide or dim unwanted bots by keywords, tags, creators and other rules. Use Smart Filter Presets, quick card actions and optional Listing Refill after filters remove results.

Chat lists and conversations

Chat folders, search and sorting, message bookmarks, chat exports, OOC presets, formatting tools, Reply Instructions and chat-history navigation. The full history reader is experimental and read-only.

Roleplay and context tools

Generation details, context warnings, Storydate, RP State, message appearance and text cleanup. Context Keeper, native Memory checks and private Lorebook helpers are experimental and require extra review.

Personas, Lorebooks and creators

Local Persona Organizer and backups, Lorebook filters/imports/exports, chatbot editor helpers, creator backups, creation history and audit tools.

Interface, backups and performance

Customize the interface, keep saved settings and lists backed up, use the Control Center and optional diagnostics, and reduce extra work in large chats or background tabs.

The complete feature list is maintained in the extension repository. Features that still need live testing are labeled experimental there, and planned items are kept separate.
