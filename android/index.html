Update architecture

The public app can check this site’s Worker for current Android release metadata. The Worker can read a tiny root update file or the latest GitHub Release and return the current APK/release information.

The actual APK install/update remains an Android user-approved action.

Release safety

Once public, the website and Android GitHub will be the maintained download sources. The same app ID and signing certificate must stay consistent for future APKs to install as updates.
