SpicyChat QoL Android

Use SpicyChat QoL as a dedicated Android app. Starting with v0.1.0, most QoL updates can update inside the app, so you usually will not need to install a new APK just because the extension changed.

Updates

You should not need a new APK for every QoL update.

v0.1.0 separates normal QoL updates from updates to the Android app itself.

Usually automatic

QoL updates

When you open the app, it checks whether 12 hours have passed since the last automatic check. If not, it leaves everything alone. If 12 hours have passed, it checks the current QoL files on GitHub.

No changes? Nothing happens. New compatible QoL files? The app downloads and applies them for you. You can also use the manual update check whenever you want.

Only when needed

Android app updates

You only need a new APK when something in the Android app itself changes. If a newer APK is available, the app asks first.

If you choose to update, it opens the download/release link so you can install the newer app. It does not silently replace the APK.

Made for Android

The app adds the Android-specific parts around QoL.

The normal QoL features stay shared with the browser extension, while the Android app handles the things that work better as part of the app.

Better Android handling

That includes things such as Android navigation, file saving, clipboard support, long-press actions, recovery tools, media handling and Android-friendly diagnostics.

Multiple chat tabs

Experimental and opt-in. It stays off by default. If you enable it, you can keep several chat conversations available and switch between them without turning it into the default experience for everyone.

Android feature list

Full QoL tools, with extra Android handling.

The app uses compatible features from the main QoL extension, such as bot blocking, saved lists, chat folders, OOC tools and other enabled features. Android-specific controls are handled by the app itself. Some desktop/browser-only options may not apply on a phone.

SpicyChat in its own app

Keep your SpicyChat session signed in, open internal links inside the app and choose your default starting page.

QoL without frequent APK installs

Compatible QoL files can update separately from the Android app. It checks about every 12 hours or when you ask it to, without reloading an active chat just to apply an update.

Save, import and back up files

Android file pickers and downloads support compatible QoL backups, chat exports and other files, with native storage handling for larger saved-data collections.

Touch-friendly chat actions

Long-press messages for supported actions such as Copy, Edit, Report, Resend or Select text. Native clipboard handling helps on mobile.

App settings and Focus Mode

Android quick controls, optional pinch-to-zoom, configurable QoL button placement and a Focus/Immersive Mode while chatting.

Optional chat tabs

Keep more than one conversation in the app and switch between them. Experimental, disabled by default, and designed to use one active WebView rather than one per tab.

Recovery and diagnostics

Checks for stalled or blank pages, WebView problems and navigation issues. Diagnostic information can help track down Android-specific bugs.

Your normal QoL organization

Where supported by the shared bundle, use chat folders, bot folders and notes, Favorites/Later/Blocked managers, filters and mobile-friendly listing controls.

The Android features above are documented in the Android project's README and changelog. The complete shared QoL feature list is maintained separately; new shared features may require a compatible app bridge or update.

Checking Android source…

Android problems can be reported in the main SpicyChat QoL issue tracker so Android and extension-side problems stay in one place.

Safe fallback

A bad QoL download should not strand the app.

The app keeps a known-good fallback. If a downloaded QoL update cannot be used with the installed Android app, it can fall back instead of forcing an incompatible update.
