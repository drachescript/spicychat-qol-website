SpicyChat QoL Android

The dedicated Flutter/WebView wrapper is open source. It keeps the shared QoL JavaScript/CSS synchronized with the extension while adding native Android behavior that a normal browser extension cannot provide reliably.

Android-only pieces

More than a WebView shell.

The current Android source includes native diagnostics/runtime bridging, black-page recovery, Android storage and file bridges, long-press message actions, configurable native controls, internal navigation, media compatibility and experimental multiple chat tabs.

Multiple Android Chat Tabs

Experimental and opt-in. It is disabled by default, uses one active WebView, keeps lightweight state for inactive tabs, supports same-bot separate conversations, restoration, closing/switching and scroll-position recovery.

Extension sync

Current content scripts, CSS, web-accessible scripts, Settings assets and feature-registry.js are synchronized into Android before builds. Browser-only tab/session features remain visibly unavailable instead of silently failing.
