Other Android ways to use QoL

The dedicated APK is not the only route. Compatible Android browsers such as Titanium or Kiwi can run the Chrome extension, and Firefox Android can use the Firefox build when the current Firefox release supports it.

Waterfox Android is a special case: the Gecko side can be compatible, but arbitrary third-party XPI installation is the current blocker.

Update architecture

The website Worker is ready to read a tiny Android update file or the latest GitHub Release and return current APK/release metadata. The actual APK install/update remains a normal Android user-approved action.

Planned

Android parity keeps moving after v0.2.

Multiple chat tabs, wrapper-specific navigation fixes, file/import-export reliability, mobile placement and other Android-only behavior stay separate from the browser release so the website can describe their status honestly.
